Product teams that ship AI features are changing how they release model updates. Several large consumer apps now run an online experiment for every model change, comparing the new model against the old one on real users before a full rollout.

Teams now require an online experiment before any model change reaches all users. The experiments track task success, user retention, and complaint rates, not only offline benchmark scores.

Leaders say offline evaluation is still the first gate. A model that fails the internal eval suite never reaches an experiment. But passing evals is no longer enough on its own.

One analyst said inference prices could keep rising for the largest models, which makes long experiments expensive.

Program managers are being asked to own the rollout plan: who sees the new model, which metrics decide the launch, and when to roll back.
